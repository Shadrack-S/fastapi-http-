# 🚀 FastAPI Learning Journey

This repository contains my hands-on practice and learning exercises while exploring **FastAPI**, one of the fastest Python web frameworks for building APIs.

## 📚 Topics Covered

* Understanding the **anatomy of a FastAPI application**
* Setting up projects using the **uv** package manager
* Running applications with the **Uvicorn ASGI** server
* Understanding the **request–response lifecycle**
* Data validation using **Pydantic**
* Working with **GET** requests

  * Query Parameters
  * Path Parameters
* Building APIs with:

  * **POST** – Create resources
  * **PUT** – Update resources
* Automatic API documentation with **OpenAPI**

  * Swagger UI
  * ReDoc
* Important packages

  * `python-multipart` (Form and File uploads)
  * `pydantic`
  * `uvicorn`
  * `fastapi`

## 🛠️ Tech Stack

* Python
* FastAPI
* Uvicorn
* uv
* Pydantic

## 🎯 Goal

The goal of this repository is to build a strong foundation in FastAPI by learning its core concepts, understanding API development best practices, and creating small examples for each feature.

More topics such as dependency injection, authentication, database integration, middleware, and deployment will be added as I continue learning.

Happy Learning! 🚀
